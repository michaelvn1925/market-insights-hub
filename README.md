# Market Insights Hub — GitHub Pages starter

This is a static starter website inspired by the publicly visible structure and content of the Wix site:
https://michaelvnosa.wixsite.com/data-insights-market

## Files
- `index.html` — page content and structure
- `style.css` — responsive visual design
- `script.js` — small dynamic footer-year update

## Publish with GitHub Pages
1. Create a **public** repository named `market-insights-hub` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for the Pages deployment, then open the URL shown in Settings → Pages.

Official instructions: https://docs.github.com/en/pages/quickstart

## Before publishing
- Replace the placeholder `hello@example.com` email in `index.html` with your preferred contact email, or remove the contact button.
- Review all content and confirm any statistics, client testimonials, names, and performance claims are accurate. This starter omits the Wix site's numerical metrics and testimonials to avoid presenting unverified claims as facts.
- This is a **recreation**, not a direct export of Wix's original source or site functionality. Wix-specific CMS, forms, animations, and other platform features are not automatically transferred.
- The visual uses Google Fonts via an external stylesheet; the site still works with fallback fonts if Google Fonts are unavailable.
